# TimeMaster - Sistema de Agenda

**Aluna:** Liriel Felix

## Funcionalidades
- Cadastro de compromissos pessoais e profissionais
- Edição, busca e remoção de compromissos
- Listagem ordenada por data, prioridade ou categoria
- Verificação automática de conflitos de horário
- Validação de data (não permite datas passadas)
- Sistema de prioridade (1-5) para organização

## Como Compilar e Executar

```bash
javac Main.java
java Main
```

**Observação:** O sistema apresenta um menu interativo para navegação.
